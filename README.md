> libremis is a lightweight, read-only local service that exposes a modern, cached REST API over legacy SIMS .net instances.
>
> Designed for school IT administrators and developers, it decouples automation scripts, plugins, and web apps from proprietary 32-bit client binaries.
> By orchestrating native, supported reporting utilities behind an in-memory cache, it lets you query normalized pupil, staff, and timetable data in milliseconds via Python, PowerShell, or JavaScript—without touching raw SQL or voiding support warranties.
